## Правки главной (после приёмки фазы 3)
- **Instagram-блок** — другие кадры, чем в «Хочу так само»: веер типс, светлый манікюрний стіл, набор у крафт-пакете, ножницы й апельсинова паличка, педикюрная зона, одноразовий набор.

## Фаза 5 — функционал

- **`functions/api/lead.ts`** → Telegram: запись (`src/lib/lead.ts#validateLead`) и **сертификат** (`kind = sertyfikat`, `validateCert`). Сервер пересчитывает цену записи (топ +20 %) и сумму сертификата (номинал из списка или цена услуги — не со страницы), проверяет слот, мастера и группу.
- **Честный fallback без секретов**: JSON **503** «Не вдалося надіслати… Зателефонуйте 057 000 21 21 або напишіть у Telegram» + ссылки; без JS — **303** на `#ne-nadislano` (блок через `:target`). Telegram недоступен → 502 и то же сообщение. Ошибки полей → 422 / 303 на `#pomylka`. Honeypot → поддельный успех. Украинские номера: `0XX…`, `+380…`, 9 цифр, со скобками и дефисами.
- **«Дякуємо»** (`/zapysano/`, noindex): сводка (послуга, колір, майстер, коли, гарантія до …) и **«Що далі»** — для записи (підтвердження за 15 хв → нагадування за день → пакет відкриють при вас) и отдельно для сертификата (посилання на оплату → сертифікат у месенджер або крафт-конверт → 6 місяців).
- **SEO**: title / description / canonical на каждой странице; OG-картинки на 8 страниц (`public/og/`, язык «Віяло»: фарфор, заголовок, фото в арке-типсе без текста поверх) + twitter card; schema.org `BeautySalon` + `NailSalon` с `openingHoursSpecification` и услугами как `Offer` (главная, контакты), `FAQPage` (главная, контакты), `BreadcrumbList` на внутренних; favicon SVG + PNG 32 / 180 / 192 / 512, `site.webmanifest`; sitemap без `/styleguide`, `/zapysano`, `/404`; `robots.txt` и `llms.txt` на `vyshnia-beauty.pages.dev` (curl 21.10.2026 → `000`, свободно); `_headers` (кэш `/_astro/*` и `/fonts/*`, nosniff, referrer, permissions).
- **Конфиги**: `wrangler.toml` `name = "vyshnia-beauty"`, `.node-version` = 22, `.dev.vars.example` с пустыми `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`.

**Найдено и исправлено в фазах 4–5:**
- нативная проверка `required` блокировала отправку раньше JS, и наши сообщения об ошибках не показывались → `noValidate` при работающем JS (без JS `required` остаётся);
