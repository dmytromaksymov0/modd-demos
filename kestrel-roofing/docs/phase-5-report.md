## Форма → Telegram

| Что | Где |
|---|---|
| Pages Function `POST /api/lead` | `functions/api/lead.ts` |
| Валидация и текст сообщения (общие для сервера и тестов) | `src/lib/lead.ts` |
| Env | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (секреты Pages); `TELEGRAM_API_BASE` — только для локального теста |
| Конфиг Pages | `wrangler.toml` (output `dist`), пример локальных секретов `.dev.vars.example` |

Как работает:
- **С JS:** двухшаговая форма шлёт `fetch` и получает JSON. Ошибки сервера (422) показываются под нужным полем, при успехе — экран «Got it» и событие `kestrel:lead` для аналитики.
- **Без JS:** обычный POST. Успех → `303 /thanks/`. Ошибка → `303 /free-inspection/?error=1#form-error`, плашка ошибки видна через `:target`, без скриптов.
- **Защита от спама:** honeypot-поле `company`. Бот получает «успех», в Telegram ничего не уходит.
- **Отказоустойчивость:** нет env → `503`; Telegram недоступен → `502`. В обоих случаях человеку предлагают позвонить, ошибка пишется в лог Pages.
- **Сообщение в Telegram:** тип проблемы, имя, телефон (кликабельный `tel:`), ZIP + город или пометка «outside service area», расчёт из калькулятора (если был), страница, время по Columbus. HTML экранируется.

## SEO и служебное
- **OG-картинки 1200×630** для каждой страницы, в стиле Field Report: реальное фото + выноска. Генератор — `scripts/make-og.cjs`, результат в `public/og/`. Подключены `og:image` и `twitter:card=summary_large_image`.
- **Favicon:** SVG + PNG 32, apple-touch-icon 180, icon-512.
- **Schema.org** на каждой странице: `RoofingContractor`, `FAQPage` (где есть FAQ), `BreadcrumbList`.
- **title / description / canonical** на каждой странице.
- **Sitemap** (`@astrojs/sitemap`): 8 страниц, без styleguide и thanks. `robots.txt` со ссылкой на sitemap.
- **Страница 404** («Inspection #404 · we checked every slope») и **/thanks/**, обе noindex.
- **`public/_headers`:** nosniff, referrer-policy, permissions-policy, запрет фреймов, вечный кеш для `/_astro/*`.
- **Аналитика:** заготовка GA4 / Plausible в `src/config/site.ts`, по умолчанию `provider: 'none'` — ни одного скрипта на странице. При включении успешная заявка уходит событием `Lead` / `generate_lead`.

## Что нужно от тебя для живой формы
Настоящая отправка заработает после деплоя, когда в Cloudflare Pages появятся `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Бота и чат создаёшь ты: токены я не ввожу и не храню. Инструкция — в README. До этого форма на живом сайте честно отвечает «Form is not configured yet. Please call us».
