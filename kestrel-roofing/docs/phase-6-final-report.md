## Найдено и исправлено на финальном QA
1. **Поле ZIP без видимого фокуса** с клавиатуры: класс `focus:outline-none` в компоненте Field перебивал кольцо фокуса. Исправлено во всех формах.
2. **Мелкие цели касания на телефоне:** ссылка-логотип (36 px), текстовые ссылки-кнопки (27 px), слайдеры (32 px), телефон в CTA, email. Все доведены до ≥ 44 px.
3. **Страница Storm при загрузке сама прокручивалась вниз** к шагам страхового случая на телефоне и планшете: `scrollIntoView` в компоненте двигал всю страницу. Теперь прокручивается только полоса шагов. Добавлен регрессионный тест.
4. Projects на 768: у широкого кейса текстовая колонка была узкой — двухколоночная раскладка теперь только с 1024 px.
5. Длина description на главной, Storm, 404 и thanks.
6. Добавлены `moz-range-thumb` focus для Firefox и `.node-version` для сборки на Cloudflare.

## Что осталось (не блокирует сдачу)
- **Деплой.** Нужен вход в Cloudflare (`npx wrangler login` или подключение репозитория в дашборде) и секреты `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`. Пароли и токены я не ввожу — это делаешь ты. После входа могу выполнить команды из README.
- **Git.** Проект пока не под git. Для варианта «деплой через Git» его нужно инициализировать и запушить — по твоему слову.
- **Фото** — стоковые, реальных американских объектов, но не из Огайо; пар «до/после» нет (слайдер готов, но выключен). Для реального клиента — его фото, см. README.
- **LCP 1.7–2.3 s** — на страницах с большим фото чуть выше цели ≤ 2.0 s. Это лабораторный замер на эмуляции медленного 4G; дальше ужимать можно только ценой качества фото.
- **Стандарт студии.** В общем `../CLAUDE.md` всё ещё написано «Astro 5», а Kestrel на Astro 7 (решение фазы 3). Обновлять стандарт для остальных четырёх сайтов — на твоё решение.
