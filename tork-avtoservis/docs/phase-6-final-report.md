## 2. Заявки без подключённого бота
Секретов `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` пока нет — так решено. Проверено, что посетитель никогда не упирается в тупик.

- **Функция** отвечает `503`, не `500`, с телом `{ ok: false, delivery: true, errors.form }`. Текст: «Не вдалося надіслати заявку — зателефонуйте +380 57 000-14-14 або напишіть нам у Telegram чи Viber.»
- **Тот же ответ** при сбое Telegram (`502`) и битом запросе (`400`).
- **Без секретов в Telegram ничего не уходит.**
- **С JS:**
  - форма остаётся на странице;
  - открывается блок «Не вдалося надіслати заявку. Запишемо вас інакше:» с тремя крупными ссылками — телефон (`tel:`), Telegram, Viber;
  - фокус переходит на блок (`role="alert"`), кнопка снова активна;
  - то же при отсутствии сети.
- **Без JS:**
  - `303` обратно на ту же страницу `?pomylka=nadislaty#ne-nadislano`, блок появляется через `:target`;
  - это отдельный блок от «перевірте номер телефону» (`#pomylka`), чтобы не путать причину.
- **Ссылки в блоке.** Отдельные кнопки Telegram/Viber у компании нет, поэтому в `site.ts → messengers` добавлены прямые ссылки на демо-номер: `t.me/+380570001414`, `viber://chat?number=%2B380570001414`. Они никуда реально не ведут, в README — пункт заменить на аккаунт менеджера.
- **Консоль:** e2e ловит `pageerror` и `console.error` — **0**.
  - Единственная строка в консоли при отправке — сообщение самого браузера о статусе запроса («Failed to load resource: … 503»). Это не исключение страницы.
  - Его не убрать, не отказавшись от правильного HTTP-статуса.
- **Тесты:** 2 unit (JSON 503 с телефоном и мессенджерами; без JS → 303 на `#ne-nadislano`) + 4 e2e (JS: 503 + блок + остаёмся на странице; фокус и кнопка; нет ошибок в консоли; без JS → блок через `:target`).

  - вес в 10 и 4 раза меньше;
  - Best Practices 100 против 96 и 77;
  - доступность 100 против 95 и 97;
  - ни одного стороннего скрипта и cookie;
  - функции из списка ниже.

**Чего нет ни у одного из пяти** (фирменные моменты):
1. **«Ремонт у чаті» с кошторисом, который можно погодити.** Процесс показан как переписка с мастером. В кошторисе «Терміново / Можна відкласти / Не потрібно» человек сам выбирает «Робимо / Відкласти», итог пересчитывается, выбор уходит в заявку. Все конкуренты *говорят* «без вашого погодження не робимо» — ТОРК это *показывает*.
2. **Калькулятор «від Lanos до Land Cruiser».** Класс авто через узнаваемые модели × любые из 22 работ, совмещённые операции дешевле (колодки + диски: −440 ₴ для класса C), время на подъёмнике. Расчёт переносится в заявку, и сервер пересчитывает его сам: подставленная цифра не пройдёт.
3. **«Що турбує?»** — симптом своими словами («стукає спереду на ямах») подсвечивает нужную услугу.

Плюс:
- цены по классам A–D с липкой шапкой нормо-часов;
- живой статус «Відчинено до 19:00» по киевскому времени;
- «Працюємо під час відключень: генератор + Starlink» с конкретикой и строкой про тревогу;
- старые детали «в пакеті з номером замовлення»;
- форма, которая работает без JS.
