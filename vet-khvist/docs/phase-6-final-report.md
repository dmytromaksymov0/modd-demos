## 5. Что осталось и риски

- **Тексты «Чи терміново?» и «що робити дорогою»** консервативны, но для реальной клиники их обязательно должен проверить и подписать головний лікар.
- **Комендантська година 00:00–05:00** взята из открытых источников (2025–2026). Перед запуском сверить с Харківською ОВА.
- **Фото:**
  - 3 врача — стоковые модели под вымышленными именами;
  - операционной нет: для «Хірургії» — кадр стерильных инструментов;
  - для реального клиента нужна съёмка (см. README).
- **Название:** в Киеве есть реальная ветклиника «Хвіст» — для реального клиента проверить торговую марку.
- **Для основной сессии, вне этой папки:** открытый редирект в ТОРК — `tork-avtoservis/src/lib/lead.ts`, строки 76 и 116: регулярка `^\/[\w\-/]*$` пропускает `//host`. Исправление — одна регулярка, как в `vet-khvist/src/lib/lead.ts` (`^\/(?!\/)…`).

## 6. Правка после ревью (22.10.2026): «що робити дорогою» по выбранному

- **Было:** в исходе «Їдьте зараз» список советов один для всех. У кота с флагом «лоток без сечі» показывалось «Собаку з травмою — на твердій поверхні».
- **Стало:** `onTheWay(flags, species)` в `src/lib/triage.ts`:
  - у каждого из 10 флагов свои 1–3 пункта «Що робити дорогою» и «Чого не робити». Тексты взяты из 9 ситуаций /nevidkladna, тест следит, что формулировки совпадают. Для «набряку морди» и «крові в блюванні» своих ситуаций на /nevidkladna нет — у них свои короткие тексты;
  - несколько флагов → один список без дублей, по тяжести (дихання → набряк → кровотеча → здуття → судоми → отруєння → сеча → травма → кров у ШКТ → пологи). Не больше 5 пунктов «робити» и 4 — «не робити»;
  - вид: пункты про кота показываются только для кота. На шаге красных флагов вид ещё не известен — тогда только нейтральные формулировки, без переноски и без «кота / собаку»;
  - общие пункты («подзвоніть дорогою», «тримайте в теплі», «не давайте їжу й ліки людини») остаются, но уступают правилу флага на ту же тему. Дихання → прохолодне повітря вместо «тримайте в теплі». Здуття → «подзвоніть — підготуємо операційну», «не годуйте й не поїть». Отруєння → «візьміть упаковку», «не давайте нічого»;
  - правило «кіт + сеча + стає гірше» (исход «now» из шага 2) получает советы про сечу.
- **/nevidkladna:** две формулировки сделаны нейтральными и строже, чтобы совпадать с триажем. «Закупорка небезпечна за години» — без «у котів». При отруєнні — «не давайте нічого: ні їжі, ні води, ні молока, олії чи активованого вугілля».
- **Интерфейс:** в исходе «Їдьте зараз» рядом с «Що робити дорогою» появился блок «Чого не робити» с иконкой ×. Правила безопасности триажа (уровни) не менялись.
- **Проверки:**
  - `npm test` — **43 / 43**: +9 тестов на подбор советов, 1 старый тест «отрута» заменён;
  - `npm run e2e:triage` — **26 / 26** (главная и /nevidkladna);
  - `npm run e2e` — 17 / 17, `test-home` — все сценарии, ссылки — OK;
  - QA главной и /nevidkladna × день / ночь / комендантська × 5 ширин — 30 / 30;
  - Lighthouse главной — 100 / 100 / 100 / 100, LCP 1,7 с, 131 KB, 7 запросов.
- **Не менял, на решение:** в комендантську годину исход «Їдьте зараз» показывает текст комендантської години, но заголовок «Що робити дорогою» и пункт «Подзвоніть дорогою» остаются. Можно переключать их на «Що робити зараз» / «Подзвоніть — лікар скаже, що робити до 05:00».
