## 2. Логика и безопасность «Чи терміново?»

`src/lib/triage.ts`, 11 тестов в `tests/triage.test.ts`.

- **Любой красный флаг → «now»**, без дальнейших вопросов. Проверено для каждого из 10 флагов.
- **Неопределённость только поднимает уровень, никогда не опускает.** До минимум «today» поднимают:
  - кошеня или цуценя (до 6 міс);
  - тварина 8+ років;
  - «стає гірше»;
  - симптомы из 2+ зон;
  - «Інше / не знаю».
- **Кот с проблемами мочеиспускания, которые ухудшаются → «now»** (риск закупорки). У собаки в той же ситуации — «today».
- Ни один симптом не классифицирован ниже «plan». «Now» возникает только из флагов или правила для кота.
- В каждом исходе:
  - номер текстом;
  - «Це не діагноз… Сумніваєтесь — дзвоніть»;
  - у «today» и «plan» — путь вверх «Їдьте зараз, якщо з’явиться важке дихання, кров, судоми, тварина не встає або перестала пити».
- **«Що робити дорогою»** — только практичные вещи: подзвонить, переноска / твёрдая поверхность, без ліків людини, тепло. При отравлении добавляется «візьміть упаковку».
- **В комендантську годину** исход «Їдьте зараз» показывает утверждённый текст вместо «подзвоніть дорогою».
- Неизвестные id из запроса игнорируются, им не доверяем.
- «Записатися» из исходов «today» и «plan» переносит результат в форму: «Результат «Чи терміново?»: Планово…». Он уходит в Telegram-заявку строкой «Чи терміново?».

## 3. Заявка и честный fallback

`src/lib/lead.ts` + `functions/api/lead.ts`, 6 тестов в `tests/lead.test.ts`.

**Поля:**
- обязательный — только телефон (украинская нормализация: 0XXXXXXXXX / +380 / 9 цифр);
- необязательные — повод (только из списка), вид, кличка, имя, удобное время, «що турбує», канал ответа (дзвінок / Telegram), результат триажа;
- honeypot `company`.

**Проверено через `wrangler pages dev dist` без секретов:**
| Запрос | Ответ |
|---|---|
| fetch, телефон верный | **503** + «Не вдалося надіслати заявку — зателефонуйте 057 000 24 24, черговий адміністратор запише вас.» Форма показывает блок с номером |
| без JS, телефон неверный | 303 → `/?pomylka=1#pomylka`, блок проверки номера (`:target`) |
| без JS, телефон верный | 303 → `/?pomylka=nadislaty#ne-nadislano`, блок с номером |
| бот (honeypot) | 303 → `/dyakuyemo/`, без отправки |

**Найдена и исправлена дыра — открытый редирект.** Проверка пути `^\/[\w\-/]*$` пропускала `//evil.example`: протокол-относительный адрес уводит на чужой сайт. Теперь используется `^\/(?!\/)…` и есть тест на это. **У ТОРК та же регулярка** (`tork-avtoservis/src/lib/lead.ts`, строки 76 и 116). В ТОРК я не исправлял — это вне моей задачи, передаю основной сессии.

## 4. JS по первому взаимодействию

- `src/lib/home-ui.ts` (триаж, календарь, отправка формы) подгружается динамическим `import()` при первом `pointerdown / focusin / keydown / change` на виджете.
- Клик, пришедший до загрузки модуля, повторяется после неё: **первый тап не теряется** — проверено на «Так, є» сразу после загрузки страницы.
- Модуль загружается сразу, только если URL этого требует: `?pryvid=` или `?pomylka`.
- Проверка (Playwright): до взаимодействия запросов к `home-ui` — 0, после первого клика — 1.

**Сквозные сценарии** (`scripts/test-home.cjs`, скриншоты `screenshots/flow-*.png`):
1. «Так, є» без отметок → «Їдьте зараз».
2. Отравление → «візьміть упаковку».
3. Взрослый пёс + свербіж → «Планово».
4. Перенос результата в форму.
5. Пустой шаг 2 → понятная ошибка.
6. Календарь «собака, 8+» → даты с 25 жовтня и реплика бота «Рексу через 14 днів — щорічна ревакцинація».
7. Форма: пустой телефон → ошибка у поля; верный телефон без функции → блок с номером.

После результата триажа заголовок исхода получает фокус и оказывается в зоне видимости: 161 px от верха на 1280, 153 px на 375.

**Самокритика — что нашёл и исправил**
1. **320 px, горизонтальный скролл** — три причины:
   - у сеток секций не было `grid-cols-1`, колонка растягивалась по контенту (пузырь бота, `input type=month`);
   - кнопка «Надсилати нагадування в Telegram» не переносилась;
   - таблица цен не помещалась.

   Всё исправлено: `grid-cols-1 min-w-0`, перенос текста кнопки, меньшие отступы таблицы.
2. Бейдж «все включено» растягивался на всю ширину колонки — `justify-self-start`.
3. В таблице цен не было подписи, что колонки по весу относятся к собаке — добавил группу «Собака, вага».
4. Секции «Світло» и «Клуб» шли подряд с одинаковым фоном и сливались — поменял чередование фонов.
5. Типографика:
   - двойное тире «— −10 %» в двух местах переписал как «знижка 10 %»;
   - «Санація ротової порожнини під наркозом» занимала 3 строки — сократил до «Санація зубів під наркозом»;
   - примечание к прививке «…лептоспірозу і сказу» переписал на «…, а також від сказу».
6. **Отзыв** «подзвонила о пів на першу ночі… коли ми приїхали» означал поездку в комендантську годину — время изменено на 23:00.
7. **Подпись к фото** «Дмитро Савчук слухає шпіца»: на кадре не видно, что он слушает — заменил на «тримає шпіца».
8. Второе свечение в ночной секции убрал: по правке 5 свечение одно, и оно в hero.
9. QA-скрипт считал honeypot элементом за краем и маленькой целью касания — теперь он пропускает `aria-hidden`.
