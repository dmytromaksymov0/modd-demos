# Ветклініка «Хвіст» — концепт-сайт

Адрес после деплоя: **https://vet-khvist.pages.dev** · Демо для портфолио **modd.**

Сайт вымышленной круглосуточной ветклиники в центре Харькова (9 врачей) на украинском языке. Два главных действия:
- **звонок** в экстренной ситуации;
- **онлайн-запись** на плановый визит.

Astro 7 + Tailwind CSS 4, статическая сборка и одна Cloudflare Pages Function для заявок.

**Страницы:**
- Головна, Невідкладна допомога;
- Послуги и 4 страницы услуг (Терапія, Хірургія, Вакцинація, Діагностика);
- Ціни (вкладки Коти / Собаки), Лікарі, Клуб турботи, Запис;
- Дякуємо, Приватність, 404, `/styleguide` (noindex).

**Фирменные моменты**
- **«Чи терміново?»** — триаж без диагноза. Сначала красные флаги: хоть один → «Їдьте зараз». Потом вид, возраст, симптомы и динамика → «Їдьте зараз / Сьогодні / Планово».
  - Неопределённость только поднимает срочность.
  - Номер виден в каждом исходе, есть «Що робити дорогою».
  - Логика покрыта тестами (`src/lib/triage.ts`).
- **«Ніч у Харкові»** — сайт живёт по киевскому времени.
  - Днём двери «Терміново / Планово» стоят 7:5.
  - С 22:00 шапка темнеет, «Терміново» расширяется до 8:4.
  - С 00:00 до 05:00 вместо «приїжджайте» — утверждённый текст про комендантську годину.
  - Без JS сайт показывает статичный «Цілодобово». Посмотреть ночь днём: `?t=night` или `?t=curfew`.
- **«Календар турботи»** — даты щеплень, обработок и чекапов для конкретного животного. Рядом пример сообщения Telegram-бота с пометкой «приклад повідомлення».
- **Ещё:**
  - цены «все включено» по весу собаки;
  - плашка «Операційна працює без світла · генератор + Starlink»;
  - график «Чергові цього тижня».

**Lighthouse (mobile), все индексируемые страницы:** Performance 100 · Accessibility 100 · Best Practices 100 · SEO 100 · LCP 1,5–1,9 с · CLS 0 · вес 96–220 КБ.
Полные цифры и сравнение с пятью реальными ветклиниками Харкова, Киева и Львова — в `docs/phase-6-final-report.md`.

## Требования
- Node.js ≥ 22.22 (Astro 7). `.node-version` фиксирует 22 для Cloudflare. Локально проверено на Node 25.
- Для живых заявок нужны аккаунт Cloudflare и Telegram-бот. Их можно подключить позже — см. ниже.

## Запуск
```bash
npm install
npm run dev
```

`astro dev` не запускает функцию заявок. Чтобы проверить сайт целиком вместе с функцией:
```bash
cp .dev.vars.example .dev.vars
npm run build
npx wrangler pages dev dist
```
В `.dev.vars` (в git не попадает) — токен бота и chat id. Без них форма честно отвечает «Не вдалося надіслати заявку» и даёт номер телефона.

## Деплой на Cloudflare Pages — только через Git-интеграцию
Сайт живёт в общем репозитории `dmytromaksymov0/modd-demos` (ветка `main`), в папке `vet-khvist/`.

Деплой **только** через Git-интеграцию Pages. Не используйте Direct Upload и `wrangler pages deploy` для нового проекта: такой проект потом нельзя подключить к Git.

1. Дашборд Cloudflare → **Workers & Pages → Create → Pages → Import an existing Git repository** (не мастер Workers) → `dmytromaksymov0/modd-demos`.
2. Настройки сборки:

   | Параметр | Значение |
   |---|---|
   | Project name | **`vet-khvist`** — совпадает с `name` в `wrangler.toml`. Адрес `vet-khvist.pages.dev` проверен curl 21.10.2026: ответа нет (`000`), имя свободно |
   | Production branch | `main` |
   | Framework preset | Astro |
   | Root directory | **`vet-khvist`** |
   | Build command | `npm run build` |
   | Build output directory | `dist` |
   | Переменная окружения | `NODE_VERSION` = `22` |
   | Build watch paths (Settings → Builds) | include **`vet-khvist/*`** — тогда коммиты в другие демо не пересобирают этот сайт |

3. Папку `functions/` Cloudflare подхватывает сам.
4. `public/_headers` задаёт заголовки безопасности. Там `X-Frame-Options: SAMEORIGIN`: стайлгайд показывает первый экран в iframe. Ещё заголовки включают долгий кеш для `/_astro/*` и `/fonts/*`.
5. **Если адрес получил суффикс** (например `vet-khvist-xyz.pages.dev`): поменяйте `site` в `astro.config.mjs` и строку `Sitemap:` в `public/robots.txt` на фактический адрес, затем запушьте.

### Telegram-бот (можно позже)
Пока секретов нет, функция отвечает `503`. Форма показывает «Не вдалося надіслати заявку. Запишемо вас по телефону» с номером — и с JS, и без JS. Ошибок 500 и заявок, потерянных без объяснения, нет.

1. В Telegram: **@BotFather** → `/newbot` → скопировать токен.
2. Создать группу для заявок (или взять личный чат), добавить туда бота и написать любое сообщение.
3. Открыть `https://api.telegram.org/bot<TOKEN>/getUpdates` и взять `chat.id`. У групп он начинается с `-100…`.
4. Pages → **Settings → Variables and Secrets** → добавить как *Secret* (Production; при желании и Preview):

   | Переменная | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
   | `TELEGRAM_CHAT_ID` | id чата для заявок |

   Или из терминала: `npx wrangler pages secret put TELEGRAM_BOT_TOKEN --project-name vet-khvist` (так же для `TELEGRAM_CHAT_ID`).
5. **Deployments → Retry deployment** — секреты применяются только к новым деплоям.
6. Отправить одну тестовую заявку с живого сайта.

Что приходит администратору:
- **Запись:**
  - телефон в формате `+380 XX XXX XX XX`, как ответить (дзвінок / Telegram);
  - имя, кот или собака, кличка;
  - поводы, удобное время, «що турбує»;
  - **результат «Чи терміново?»**, если человек пришёл из триажа;
  - страница, с которой пришла заявка, и время по Киеву.
- **Клуб турботи:** вид, возраст, последнее щеплення, телефон для Telegram.

### После первого деплоя
- [ ] Lighthouse на живом адресе, OG-превью ссылки в Telegram.
- [ ] Свой домен: **Pages → Custom domains**, затем `site` в `astro.config.mjs` и `Sitemap:` в `public/robots.txt`.
- [ ] Google Search Console: отправить `https://<домен>/sitemap-index.xml`. Google Business Profile с тем же названием, адресом, телефоном и часами 24/7.
- [ ] Аналитика (по желанию): `src/config/site.ts` → `analytics.provider = 'plausible' | 'ga4'`.

## Тесты и QA
```bash
npm test
npm run build && npm run e2e
npm run preview
```
- `npm test` — 35 unit-тестов:
  - триаж — все правила безопасности;
  - календарь, день / ночь / комендантська, в том числе переход на летнее время;
  - телефоны и валидация, сообщение в Telegram, открытый редирект;
  - сама функция с mock-fetch.
- `npm run e2e` — 17 проверок: собранный сайт + 2 × `wrangler pages dev` (с mock Telegram и без секретов), с JS и без JS:
  - триаж → запись;
  - клуб;
  - ошибки;
  - Telegram недоступен;
  - honeypot.

Пока `npm run preview` работает на http://localhost:4321, в другом терминале:
```bash
npm run qa
```
```bash
npm run test:home
```
```bash
npm run links
```
```bash
npm run qa:fonts
```
- `npm run qa` — скриншоты 320 / 375 / 768 / 1280 / 1920 всех страниц, днём и ночью (`MODES=day,night,curfew`). Проверяет:
  - горизонтальный скролл и элементы за краем;
  - ошибки консоли;
  - текст < 13 px, lamp-dim < 14 px;
  - цели касания < 44 px;
  - на телефоне — номер, адрес и «Подзвонити» на первом экране.
- `npm run test:home` — интерактив главной: ленивый JS, исходы триажа, перенос результата в форму, календарь, ошибки формы.
- `npm run links` — все внутренние ссылки и `#якоря`.
- `npm run qa:fonts` — CLS, когда шрифты приходят на 1,5 с позже.
