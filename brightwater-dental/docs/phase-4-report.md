## 2. Запись (фирменные моменты A, C, B)
- **Без JS** это обычная POST-форма на `/api/lead`: три строки людей, ещё две в `<details>`, выбор «когда» радиокнопками (first available / weeknight / Saturday / weekday), чекбоксы комфорта, страховка, контакты, honeypot. Обработчик — фаза 5; до неё отправка вернёт 404.
- **С JS** (`src/lib/book-ui.ts`) модуль грузится на idle или при первом действии. Что он делает:
  - **Дни:** 12 ближайших рабочих дней по времени Остина. Суббота на солнечной подложке, полностью занятые дни отмечены «Full».
  - **Время:** до 4 вариантов на утро, день и вечер (+ «Show all N times»). Подпись «side by side» для групп до 3 человек, «back-to-back» для 4–5. Сегодня — только с часом запаса.
  - **Превью:** дорожки кресел для выбранного слота: кто, в каком кресле, во сколько все освободятся.
  - **Состав группы:** добавить или убрать человека. Если выбранное время больше не подходит всем, оно сбрасывается.
  - **Подстановка из URL:** `?crew=family|kids`, `?visit=`, `?day=sat`, `?comfort=`, `?insurance=`, `?doctor=` — с главной, услуг, страховки и команды.
  - **Сводка** обновляется вживую: люди, время, комфорт, ответ по страховке в долларах.
- **Свободное время** — детерминированные демо-данные (хеш дата+кресло+время, `src/lib/booking.ts`, чистые функции). У реального клиента вместо этого будет API расписания.
- **Sticky-полоса на `/book` не выводится**: вся страница — сама запись.
